## 📌 1. アプリの概要と教育的ねらい

### ■ 開発の背景
高校生が直面する進路選択や総合的な探究の時間において、最大の壁となるのが**「自分を客観的に捉えること（自己分析）」**です。  
高校生の自己評価は、往々にして以下の2つのバイアスに陥りがちです。
1. **過小評価（自信の欠如）**: 「自分には特別な実績や誇れる強みがない」と思い込んでしまう。
2. **主観の偏り（環境の混同）**: 自分の努力不足と、世の中の不可抗力な変化（倍率の上昇や技術の進化など）を切り分けられず、適切な行動が取れない。

本アプリは、経営戦略の代表的フレームワークである**「SWOT分析」**と**「クロスSWOTマトリクス」**を自己分析に応用し、**「自分自身（内部要因）」と「社会環境（外部要因）」を論理的に分離**した上で、未来の行動指針（＝自分だけの羅針盤）を導き出す教育用Webアプリケーションです。

## 🧠 2. SWOT分析とクロス分析の理論的解説

### ① SWOT分析の4要素
| 要素 | 分類 | 定義と高校生における着眼点 |
| :--- | :--- | :--- |
| **Strengths（強み）** | **内部要因** (コントロール可能) | 自分が「自然とできてしまうこと」「他者から感謝されたこと」「粘り強く続けられる習慣」。自慢できる資格である必要はありません。 |
| **Weaknesses（弱み）** | **内部要因** (コントロール可能) | 「努力しても人一倍エネルギーを激しく消耗すること」「つい後回しにしがちな場面」。自己否定ではなく、特性として冷静に把握します。 |
| **Opportunities（機会）** | **外部要因** (コントロール不可) | 新入試制度（総合型選抜の拡大）、社会のAI需要、地域の課題解決プログラムなど、自分にとって追い風となる社会の動き。 |
| **Threats（脅威）** | **外部要因** (コントロール不可) | AIによる定型業務の自動化、志望学部の倍率上昇、入試制度の変更など、自分を取り巻く逆風や将来のリスク。 |

### ② クロスSWOT分析（4つの戦略マトリクス）
4つの要素を書き出すだけでは単なる現状把握で終わります。  
**「内的要因（S・W）」と「外的要因（O・T）」を掛け合わせることで、初めて「次にどう動くべきか」という具体的な戦略が生まれます。**

```
                  【機会 (Opportunities)】          【脅威 (Threats)】
              ┌─────────────────────────────┬─────────────────────────────┐
【強み (S)】   │   SO戦略（積極攻勢）        │   ST戦略（差別化・防御）    │
              │   強みを活かしてチャンスを掴む  │   強みで逆風をかわし差別化する  │
              ├─────────────────────────────┼─────────────────────────────┤
【弱み (W)】   │   WO戦略（弱点補強・協業）  │   WT戦略（専守防衛・リスク回避）│
              │   弱みを補い、好機を逃さない    │   最悪の致命傷を冷静に回避する  │
              └─────────────────────────────┴─────────────────────────────┘
```

1. **SO戦略（積極攻勢・機会最大化）**:  
   自分の得意分野を武器にして、社会や学校の追い風に真っ向から乗る「最大の勝ち筋」。志望理由書や自己PRのメインストーリーになります。
2. **ST戦略（差別化・脅威回避）**:  
   競争激化やAIの台頭などの逆風に対し、自分の強みを発揮して他者と差別化し、ピンチを乗り越える戦略。
3. **WO戦略（弱点補強・協業推進）**:  
   弱点がチャンスの足を引っ張らないよう、デジタルツールの活用や仲間・先生との協調によって補う戦略。
4. **WT戦略（専守防衛・リスク回避）**:  
   弱みと逆風が重なる「最悪の事態（燃え尽き症候群や全落ち）」を避けるため、無理な戦いを手放し、早めにバックアップ策を講じる守りの戦略。

## 🔒 3. 搭載ローカルLLM（Qwen 2.5）とプライバシー保護

### ■ 採用モデル：Qwen 2.5 (Instruct)
本アプリには、アリババが開発した高性能オープンソースLLM**「Qwen 2.5（0.5B-Instruct）」**を推論エンジンとして事前配備しています。
- **卓越した論理推論**: 軽量でありながら、ビジネスや進路戦略の文脈を正確に捉え、論理破綻のない完結した日本語を生成します。
- **4段階逐次推論**: SO・ST・WO・WTの各象限を個別に推論することで、文章が途中で切れることなく、具体的で前向きなアドバイスを最後まで出力します。

### ■ なぜ「完全ローカル推論」が教育現場で必須なのか？
学校教育の現場において、生徒の自己分析データは**「家庭環境」「進路の迷い」「学力や性格の悩み」など、最も繊細で保護されるべき個人情報**です。
- **外部クラウドへの非送信**: 一般的なクラウドAI（ChatGPT等）と異なり、入力データは外部の企業サーバーへ一切送信されません。
- **安全な探究環境**: 生徒が本音で自分の弱みや悩みを入力しても、情報漏洩やAIの追加学習データとして使われるリスクが完全にゼロです。

## ✨ 4. アプリの主な機能

1. **スタイリッシュなダークモードUI**:
   - スレートネイビー基調の目に優しい配色と、文章の折り返しがない洗練されたプロフィールバッジを配置。
2. **詳細解説アコーディオン**:
   - 生徒がいつでも「SWOT理論」「AIの仕組み」「操作手順」を学べるインフォメーションタブ。
3. **8カテゴリー × 2パターン（計16種類）の実践サンプル例文**:
   - 「理系」「文系」「体育会系」「文化系」「勉強」「学校行事」「大学進学」「就職」からワンクリックで入力欄に反映可能（自由編集対応）。
4. **一段構成（シングルカラム）の直感的な入力**:
   - 客観化を促す問いかけヒントに従って、自然に思考を整理できる縦並びフォーム。
5. **外部AI壁打ちプロンプト生成 & Markdownダウンロード**:
   - 分析結果をChatGPTやGemini等に持ち込んで「志望理由書の推敲」や「模擬面接」を行うための構造化プロンプトをワンクリック出力。

## 🚀 5. デプロイ方法（Streamlit Community Cloud）

1. 本リポジトリをフォークまたはクローンします。
2. [Streamlit Community Cloud](https://share.streamlit.io/) にログインします。
3. **「New app」** をクリックし、本リポジトリを選択します：
   - **Main file path**: `app.py`
4. **「Deploy!」** を押すだけで、数分で永続的な公開URLが発行されます。

## 💻 6. ローカル環境での起動方法

